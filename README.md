# Mini Library Management System

A console-based Mini Library Management System built using Python. This project simulates a small library where users can manage a collection of books through a simple menu-driven interface.

## Features

- Search for books in the library
- Issue available books
- Return issued books
- Add new books to the library
- Check whether a book is available or already issued
- Manage a predefined collection of books

## Technologies Used

- Python 3
